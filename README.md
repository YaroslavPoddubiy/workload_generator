# Генерування часових рядів для імітації навантаження систем мікросервісів

Це додаток з графічним інтерфейсом для генерації часових рядів, які імітують використання серверних ресурсів мікросервісами в хмарних інфраструктурах на основі ланцюгів Маркова. 
Програма підтримує завантаження датасетів, конфігураційних файлів, генерування часових рядів, збереження у базу даних та у файли, а також відображення матриць переходів та графіків часових рядів.

## 🔍 Опис проєкту

Додаток побудований на Python та PyQt5, реалізує графічний інтерфейс для роботи з моделлю генерування навантаження систем мікросервісів на основі ланцюгів Маркова. Користувач може:

- Вибирати тип конфігурації: за допомогою конфігураційного файлу або датасету
- Завантажувати датасети у форматі CSV
- Завантажувати конфігураційні файли у форматі JSON
- Вибирати конфігураційні файли та датасети з БД
- Налаштовувати параметри для генерування
- Генерувати часові ряди навантаження на основі обраної конфігурації та параметрів
- Відображати матриці переходів
- Візуалізувати часові ряди за допомогою графіків
- Зберігати згенеровані дані в базу даних та у файли

## 🧩 Структура проєкту

- `UI.py` - модуль із реалізацією графічного інтерфейсу
- `load_data.py` - модуль для завантаження датасетів і конфігураційних файлів
- `workload_generator.py` - модуль генерування часових рядів
- `db.py` - модуль для роботи з базою даних
- `plot.py` - модуль для побудови графіків
- `main.py` - головний модуль для запуску програми

## 🚀 Використання

- Відкрити додаток
- Вибрати режим конфігурації (через конфігураційний файл або датасет)
- Вибрати конфігураційний файл чи датасет з бази даних, або ж завантажити нові файли
- Вказати параметри для генерування: кількість станів, період часу, крок, кількість мікросервісів
- Натиснути кнопку `Згенерувати часовий ряд` для створення навантаження
- Відобразити матрицю переходів натиснувши кнопку `Побудувати матрицю переходів`
- Відобразити дані часового ряду, вибравши потрібний мікросервіс та натиснувши кнопку `Побудувати графік`
- Вибрати назву для групи мікросервісів та зберегти їх до БД, натиснувши на кнопку `Зберегти` в полі `Збереження в базу даних`

## 📄 Формати файлів

### Формат конфігураціного файлу
Файл JSON з двома основними параметрами:

- `States`: кількість станів (ціле число)
- `MarkovChain`: словник із трьома матрицями переходів для `CPU`, `RAM`, `CHANNEL`, кожна — квадратна матриця розміру `States x States`.  
Приклад:

```json
{
  "States": 4,
  "MarkovChain": {
    "CPU": [[0.7, 0.24, 0.05, 0.01], [0.7, 0.2, 0.09, 0.01], [0.3, 0.59, 0.1, 0.01], [0.2, 0.38, 0.4, 0.02]],
    "RAM": [[0.7, 0.24, 0.05, 0.01], [0.7, 0.2, 0.09, 0.01], [0.3, 0.59, 0.1, 0.01], [0.2, 0.38, 0.4, 0.02]],
    "CHANNEL": [[0.7, 0.24, 0.05, 0.01], [0.7, 0.2, 0.09, 0.01], [0.3, 0.59, 0.1, 0.01], [0.2, 0.38, 0.4, 0.02]]
  }
}
```

---

### Формат датасету

CSV-файл з 5 колонками:

- `Date` (формат `YYYY-MM-DD`)
- `Time` (формат `HH:MM:SS`)
- `CPU` (числове значення 0-100)
- `RAM` (числове значення 0-100)
- `CHANNEL` (числове значення 0-100)

Приклад:

```
Date,Time,CPU,RAM,CHANNEL
2013-08-12,16:40:46,3.37,5.07,12.0
```
